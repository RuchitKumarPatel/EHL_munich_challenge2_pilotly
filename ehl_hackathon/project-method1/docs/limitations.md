# Limitations

The export does not contain final outputs, usage, latency, or quality labels. Token counts are estimated from serialized input length. Quality is a proxy unless independently verified.

The logged model selection process is not randomized and true propensities are unavailable. Doubly robust estimates therefore depend on overlap and outcome-model assumptions.

The starter pricing values are assumptions for experimentation. They must be replaced by organizer-provided pricing before reporting financial claims.

The current demo uses an offline router and does not call external model APIs.
